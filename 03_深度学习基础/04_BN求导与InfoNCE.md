## 1. Batch Normalization 的 γ、β 梯度

对一个归一化集合中的第 `i` 个元素：

```text
μ = (1/m) Σ x_i
v = (1/m) Σ (x_i - μ)^2
xhat_i = (x_i - μ) / sqrt(v + ε)
y_i = γ xhat_i + β
```

令 `g_i = ∂L/∂y_i`。因为求 `γ`、`β` 的偏导时 `xhat_i` 与它们无关，链式法则直接得到：

```text
∂L/∂γ = Σ_i g_i xhat_i
∂L/∂β = Σ_i g_i
```

这个简答只要求仿射参数梯度时，不必展开复杂的 `∂L/∂x_i`；若题目明确要求输入梯度，才继续考虑均值和方差依赖全部样本。卷积 BN 通常按通道跨 batch 和空间维统计，推理时使用训练期间累计的 running mean/variance。LayerNorm 通常按单个样本的特征维归一化，训练/推理都使用当前样本统计。

**自测**：`xhat=[-1, 1]`，`g=[2, 3]`，则 `∂L/∂γ=1`，`∂L/∂β=5`。请先自己算，再看结果。

## 2. 对比学习与 InfoNCE

对比学习希望正样本表征更相近、负样本更远。对一句话做两次随机增强可构成正样本；批内其他句子可作为负样本，但语义相同的句子可能成为“假负样本”。

```text
L_i = -log [ exp(sim(z_i, z_i+)/τ)
             / (exp(sim(z_i, z_i+)/τ) + Σ_j exp(sim(z_i, z_j-)/τ)) ]
```

- `sim` 常用余弦相似度；`τ` 是温度，调节 softmax 的尖锐程度。
- 分子为正样本得分，分母同时包含正样本与负样本。
- 自监督学习并不等同于对比学习；掩码预测也是一种自监督目标。
- 比较方案时要说明样本构造、批量大小、假负样本以及评价方法。

## 3. 关联复习：交叉熵梯度

二分类 `p=σ(wᵀx+b)`，`L=-y log p-(1-y)log(1-p)`。先得 `∂L/∂z=p-y`，再由 `z=wᵀx+b` 得 `∂L/∂w=(p-y)x`、`∂L/∂b=p-y`。若 `H(P,Q)=H(P)+KL(P||Q)` 且目标分布 `P` 固定，最小化交叉熵等价于最小化这个方向的 KL；KL 一般不对称。
