# 模型评估指标

## 混淆矩阵

- TP：实际为正，预测为正。
- TN：实际为负，预测为负。
- FP：实际为负，预测为正。
- FN：实际为正，预测为负。

## 分类指标

```text
Accuracy  = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1        = 2 * Precision * Recall / (Precision + Recall)
Fβ        = (1 + β²) * Precision * Recall / (β² * Precision + Recall)
```

- 关注误报成本时重视 Precision，例如垃圾邮件拦截。
- 关注漏报成本时重视 Recall，例如疾病筛查或风险预警。
- 需要平衡 Precision 和 Recall 时使用 F1。
- 当漏报（FN）成本高于误报（FP）时，可以使用 `Fβ` 且令 `β > 1`；其中 `F2`（`β=2`）比 F1 更重视 Recall。
- 类别严重不平衡时，Accuracy 可能失真，应同时看 Recall、F1、PR-AUC。

ROC-AUC 衡量不同阈值下的排序能力；PR-AUC 对少数类更敏感。AUC 不能替代业务阈值下的 Precision 和 Recall。

## 回归指标

```text
MAE  = mean(abs(y - y_hat))
MSE  = mean((y - y_hat)^2)
RMSE = sqrt(MSE)
```

MAE 更容易解释，也相对不受异常值影响；MSE/RMSE 会更强地惩罚大误差。R² 表示相对于简单基线的解释程度，不能单独作为唯一指标。

## 面试表达模板

先说明业务中 FP 和 FN 哪一个代价更高，再选择指标；同时报告基线、验证集结果、测试集结果和实际阈值下的混淆矩阵。

## 学习记录

### 2026-09-28

- 已掌握：疾病筛查通常更重视 Recall，因为需要尽量减少 FN。
- 已掌握：垃圾邮件拦截如果误报成本高，应优先关注 Precision。
- 已掌握：降低分类阈值通常会让预测为正类的样本增加，Recall 上升、FP 增加，Precision 可能下降。
- 需强化：Accuracy 很高但 Recall 为 0，通常表示模型几乎或完全把样本预测为负类，正类样本全部漏报；关键问题是类别不平衡和 FN 占全部正类，而不是只看 FN 的绝对数量。

### 回归指标学习记录

- 已掌握：MAE 较小但 RMSE 明显较大，通常说明少量样本存在较大的预测偏差。
- 已掌握：房价预测需要结合 MAE 或 RMSE 判断具体价格偏差，不能只看 R²。
- 已掌握：当业务不能接受极端错误时，应优先选择 RMSE 更小的模型。
- 需强化：R² 衡量单个模型相对均值预测基线的误差改善，不是模型 A 与模型 B 预测结果之间的相关性；比较两个模型时，应分别计算它们在同一数据集上的 R²、MAE 和 RMSE。

### 2026-10-05 复习记录

- 需纠正：当正类只占 1% 时，模型把所有样本预测为负类即可得到约 99% 的 Accuracy；“预测为正的样本中有多少是真的正类”是 Precision，不是 Accuracy。
- 需纠正：Recall 低通常意味着 FN 多，应优先检查正类漏报、分类阈值是否过高，以及正负类分布和标签质量；阈值过低通常会使预测为正的样本增加，导致 FP 增多，而不是导致 FN 增多。
- 已掌握方向：过采样只能用于训练集，不能用于验证集或测试集，以免改变真实分布并造成数据泄漏。
- 待巩固：处理某地区 FN 特别多时，不能只直接降低阈值，还应先按地区做混淆矩阵和错误样本分析，再比较分组阈值、特征质量、标签偏差与数据分布漂移。
- 已掌握：正类占 1% 且全部预测为负类时，Accuracy 约为 0.99、Recall 为 0；由于没有预测为正的样本，Precision 的分母为 0，工程实现通常按 0 处理或标记为 undefined。
- 已掌握：降低分类阈值通常会使 TP 增加或不变、FN 减少或不变、FP 增加或不变、Recall 上升或不变；具体幅度取决于预测分数分布。
