# AI/机器学习面试学习总览

## 使用方式

- 当前第一优先级是本文件所在的 `01_模型评估与训练` 文件夹，先建立判断模型好坏和改进训练过程的能力。
- 每次学习一个小节，按“概念 -> 代码/例子 -> 练习 -> 面试表达”完成。
- 文档中的复选框用于记录进度。完成后勾选，并在对应文件追加自己的疑问和错题。
- 后续 agent 应优先读取本文件夹中的 `下一任Agent交接.md`，再从当前未完成的小节开始授课。

## 学习顺序

1. `01_模型评估与训练`
2. `02_机器学习基础`
3. `03_深度学习基础`
4. `04_PyTorch`
5. `05_Word2Vec与历时词向量`
6. `06_大模型与Agent`
7. `07_简历项目与模拟面试`

## 总体完成标准

- 能解释训练集、验证集、测试集的区别，并指出数据泄漏。
- 能根据任务选择评估指标，解释 Accuracy、Precision、Recall、F1、AUC、MAE、RMSE 的适用场景。
- 能定位过拟合、欠拟合、学习率不合适和类别不平衡等训练问题。
- 能用 PyTorch 独立完成数据读取、训练、验证、保存和测试。
- 能深入讲清简历中的历时词向量项目，并将其中的方法与机器学习基础联系起来。
- 能用结构化方式回答项目设计、失败方案和改进方向。
