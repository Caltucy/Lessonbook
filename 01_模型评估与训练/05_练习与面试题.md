# 练习与面试题

## 实践题

- 用 `sklearn` 完成一个二分类任务，输出混淆矩阵、F1、ROC-AUC 和 PR-AUC。
- 人为制造类别不平衡，比较 Accuracy 和 F1 的差异。
- 画训练集和验证集的 loss 曲线，构造并解释过拟合。
- 用 Pipeline 完成标准化和模型训练，验证没有数据泄漏。

## 高频问题

1. 训练集、验证集和测试集分别做什么？
2. 如何发现数据泄漏？
3. 什么时候用 Recall，什么时候用 Precision？
4. ROC-AUC 和 PR-AUC 有什么区别？
5. 验证集表现变差时，你会如何排查？
6. 如何处理类别不平衡？
7. 为什么要保存最佳 checkpoint，而不是最后一轮模型？
