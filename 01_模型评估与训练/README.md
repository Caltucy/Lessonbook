# 模型评估与训练

这是当前第一优先级模块。目标是能判断一个模型是否可靠，能解释训练结果，并能提出有依据的改进方案。

## 学习清单

- [x] 数据集划分、交叉验证和数据泄漏
- [x] 分类指标和混淆矩阵
- [ ] 回归指标
- [ ] 训练流程、损失曲线和过拟合诊断
- [ ] 超参数、早停和实验记录
- [ ] 类别不平衡和错误分析
- [ ] 完成一次端到端训练评估练习

## 必须能回答

- 为什么要有验证集？
- 为什么测试集不能用来反复调参？
- Accuracy 很高但 F1 很低可能是什么原因？
- 如何从训练曲线判断过拟合？
- 验证集指标不再提升时，你会检查什么？
