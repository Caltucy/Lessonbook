# 下一任 Agent 交接说明

## 用户背景

用户准备人工智能相关岗位面试。简历优势是 Python、AI 应用开发、Agent、MCP、API 中台和智能 GIS；有数据科学与大数据技术本科背景，目前为电子信息硕士。简历中的机器学习项目是历时词向量分析工具，涉及 gensim Word2Vec、SGNS、PPMI、SVD、Procrustes 对齐和余弦相似度。

## 岗位要求

岗位要求掌握机器学习、深度学习基础理论，了解常用模型训练与评估方法；熟悉 PyTorch、TensorFlow 者优先。用户目前对机器学习和深度学习有基础但需要复习，对 PyTorch 不熟悉。

## 授课优先级

必须先讲本文件夹中的模型评估与训练内容，尤其是数据划分、数据泄漏、分类/回归指标、过拟合诊断、训练曲线、调参与实验记录。不要一开始跳到 Transformer 或复杂模型。

推荐教学顺序：

1. 用一个分类例子讲清训练集、验证集、测试集和数据泄漏。
2. 用混淆矩阵推导 Accuracy、Precision、Recall、F1，并比较 ROC-AUC 与 PR-AUC。
3. 讲训练循环、损失曲线、过拟合和早停。
4. 再讲经典模型、深度学习和 PyTorch。
5. 用用户的 Word2Vec 项目做机器学习方法深挖。
6. 最后进行简历项目模拟面试。

## 每次授课格式

1. 先用直观例子解释概念。
2. 给出必要公式，但避免只背公式。
3. 给一段可运行的 Python 或 PyTorch 小代码。
4. 让用户回答 2-4 道检查题。
5. 纠正回答后，给出面试中的简洁表达。
6. 在文档中更新完成状态和用户的错误点。
