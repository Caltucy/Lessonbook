## 授课优先级

当前短期任务是准备海康威视 2027 校招 LLM 算法工程师笔试。先阅读 `../06_大模型与Agent/00_海康威视LLM笔试路线.md`，按其中的跨模块顺序授课。原有评估与训练基础已大部分完成，先做本模块剩余的端到端练习，再切入笔试专项；不要重复从第一节开始。

推荐教学顺序：

1. 用一个分类例子讲清训练集、验证集、测试集和数据泄漏。
2. 用混淆矩阵推导 Accuracy、Precision、Recall、F1，并比较 ROC-AUC 与 PR-AUC。
3. 讲训练循环、损失曲线、过拟合和早停。
4. 再讲经典模型、深度学习和 PyTorch。
5. 用用户的 Word2Vec 项目做机器学习方法深挖。
6. 最后进行简历项目模拟面试。

## 每次授课格式

1. 先用直观例子解释概念。
2. 给出必要公式，但避免只背公式。
3. 给一段可运行的 Python 或 PyTorch 小代码。
4. 让用户回答 2-4 道检查题。
5. 纠正回答后，给出面试中的简洁表达。
6. 在文档中更新完成状态和用户的错误点。

- 分类指标：能根据 FP/FN 成本选择 Precision 或 Recall，并判断降低阈值的典型影响。需巩固高 Accuracy、零 Recall 与类别不平衡的关系。
- 回归指标：能根据 MAE 与 RMSE 识别少数大误差，理解房价预测还需报告具体误差。曾把 R² 误认为两个模型效果的相关性；已解释 R² 是单个模型相对均值预测基线的比较。
- 训练诊断：能识别训练 loss 下降而验证 loss 上升的过拟合，知道用验证集选择最佳 checkpoint。需巩固训练和验证 loss 都高时的排查顺序，以及早停与剪枝的区别。
- 调参：能指出学习率过高可能造成 loss 波动，理解单次改变少量因素便于归因。已讲解 Dropout、Weight Decay、数据增强的直观含义，但尚未用练习检验掌握程度。
