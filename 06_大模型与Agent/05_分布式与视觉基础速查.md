# 低优先级补充：分布式与视觉基础

历史 AI 算法岗笔经包含分布式通信和视觉题，岗位本身更侧重 LLM。只有完成 [笔试路线](00_海康威视LLM笔试路线.md) 中的 P0/P1 后，再用本页查漏补缺。

## 分布式

- DDP 在多进程间同步梯度；AllReduce 可把各进程梯度求和/平均，使参数更新一致。
- NCCL 常用于 GPU 通信，Gloo 常用于 CPU 通信；选择还受设备、平台和具体操作支持影响。
- 数据并行不等于模型并行：前者各设备通常持有模型副本，后者把模型参数或计算拆到多个设备。

## 视觉基础

- 二维卷积单边输出尺寸：`floor((输入 + 2×padding - dilation×(kernel-1) - 1)/stride + 1)`。
- 普通卷积参数量（含 bias）：`输出通道 × (输入通道 × k_h × k_w + 1)`。
- 叠加卷积会扩大感受野；步幅和池化也改变输出尺度与感受野。
- ResNet 的残差连接把输入加到变换输出，帮助深层网络优化；维度不匹配时需要投影或其他匹配方式。
