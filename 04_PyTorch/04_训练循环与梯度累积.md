# 笔试专项：PyTorch 训练循环与梯度累积

## 需要分清的四件事

- `model.train()` 启用训练模式，影响 Dropout、BatchNorm 等模块；它本身不执行反向传播。
- `model.eval()` 切换这些模块的行为；它**不会**自动关闭梯度记录。
- `torch.no_grad()` 或 `torch.inference_mode()` 在验证/推理时关闭梯度记录；它们**不会**自动切换模型模式。
- `.backward()` 默认把梯度累加到参数的 `.grad`。常规每步先清零；梯度累积则在若干 microbatch 后才清零与更新。

## 可运行的最小例子

下面用合成二分类数据演示最后一组不足 `accum_steps` 时的处理。保存为 `.py` 后可用已安装 PyTorch 的 Python 运行；代码不会下载数据。

```python
from copy import deepcopy

import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

torch.manual_seed(42)
x = torch.randn(64, 2)
y = (x[:, 0] + x[:, 1] > 0).long()
train_loader = DataLoader(TensorDataset(x[:48], y[:48]), batch_size=8, shuffle=True)
valid_loader = DataLoader(TensorDataset(x[48:], y[48:]), batch_size=8)

model = nn.Linear(2, 2)
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.05)
accum_steps = 4
best_accuracy = -1.0
best_state = None

for epoch in range(5):
    model.train()
    for step, (features, labels) in enumerate(train_loader):
        if step % accum_steps == 0:
            optimizer.zero_grad()
        window_start = (step // accum_steps) * accum_steps
        window_size = min(accum_steps, len(train_loader) - window_start)
        loss = loss_fn(model(features), labels) / window_size
        loss.backward()
        if (step + 1) % accum_steps == 0 or step + 1 == len(train_loader):
            optimizer.step()

    model.eval()
    correct = total = 0
    with torch.inference_mode():
        for features, labels in valid_loader:
            predictions = model(features).argmax(dim=1)
            correct += (predictions == labels).sum().item()
            total += labels.numel()
    accuracy = correct / total
    print(f"epoch={epoch + 1} valid_accuracy={accuracy:.3f}")
    if accuracy > best_accuracy:
        best_accuracy = accuracy
        best_state = deepcopy(model.state_dict())

model.load_state_dict(best_state)
print(f"best_valid_accuracy={best_accuracy:.3f}")
```

示例中每个 microbatch 大小相同，因此对当前累积窗口的 `loss` 除以 `window_size` 可以保持梯度尺度。若最后一个 microbatch 样本数不同、loss 使用 mean reduction，想严格等价于按样本求平均，需要按实际样本数加权；BatchNorm、Dropout 等行为也可能使梯度累积与真正的大 batch 不完全相同。
