## 自拟分组背包练习

**这不是历史笔经原题的完整题面。** 自行定义输入格式：第一行是组数 `G` 和容量 `C`；之后每组先给候选数 `t`，再给 `t` 对“体积 价值”（可分行或以空格分隔）。每组最多选一个，也可以不选。输出最大总价值。

```text
输入
2 5
2 2 3 3 4
2 2 4 4 6

输出
8
```

状态 `dp_g[c]` 表示考虑前 `g` 组且容量不超过 `c` 的最大价值。转移时每个候选只能从**上一组**的状态计算：

```text
dp_g[c] = max(dp_{g-1}[c], max_k(dp_{g-1}[c-v_gk] + w_gk))
```

完整 Python 标准输入输出程序：

```python
import sys


def solve():
    values = list(map(int, sys.stdin.buffer.read().split()))
    if not values:
        return
    groups, capacity = values[0], values[1]
    pos = 2
    prev = [0] * (capacity + 1)

    for _ in range(groups):
        count = values[pos]
        pos += 1
        current = prev[:]
        for _ in range(count):
            volume, reward = values[pos], values[pos + 1]
            pos += 2
            for c in range(volume, capacity + 1):
                current[c] = max(current[c], prev[c - volume] + reward)
        prev = current

    print(prev[capacity])


if __name__ == "__main__":
    solve()
```

时间复杂度 `O(C × 候选总数)`，空间复杂度 `O(C)`。`current` 始终从 `prev` 转移，避免同组取多个；候选循环中的容量顺序在这里不影响正确性，因为读取的是上一组数组。

## 边界测试

- `G=0` 或容量 `C=0`，输出 0（假定体积均为正整数）。
- 候选体积全部大于容量，输出 0。
- 只有一组且有多个可选物品，结果只能取其中一个。
- 输入中组数据跨行时，按空白解析仍然正确。
